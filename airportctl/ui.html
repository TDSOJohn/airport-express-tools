Join a Wi-Fi network

Makes the Express a client of your WPA2 router, so AirPlay works on your home network. The 2.4 GHz radio joins it; the 5 GHz network stays up. This uses our own wpa_supplicant, copied to the Express's flash, because the firmware's built-in client mode doesn't work on 7.8.1. Needs the debug SSH login turned on first (dbug=0x3000, see docs/dbug.md): that is a root shell guarded only by the admin password.

Experimental: the firmware's built-in client mode

Doesn't connect on firmware 7.8.1: Apple's own wpa_supplicant crashes at startup (docs/join-mode.md). Writing this also switches the other radio off, so after the reboot you lose that network and gain nothing. It's here for research; undo it by restoring the backup it makes.
